# 90일 실행 체크리스트 (하루 2시간)

> 메인 전략은 [`README.md`](./README.md) 참고. 이 문서는 **그냥 위에서부터 따라 하면 되는** 주차별 액션 리스트입니다.
> KPI 원칙: 매출은 통제 불가 → **"주 5개 출시"를 통제 지표로** 삼고 그것만 사수합니다.

## Week 1 — 기반 세팅
- [ ] 메인 니치 1개 확정 (추천: Notion 생산성 템플릿 → Canva/PDF 변주)
- [ ] Claude에 페르소나 5 + 키워드 20 + 첫 템플릿 10 아이디어 요청
- [ ] Canva 브랜드 키트 1개 생성 (컬러 2~3, 폰트 2)
- [ ] Etsy 샵 골격(이름/배너/정책/소개) 세팅
- [ ] Gumroad 프로필 + Payoneer 연결 확인
- **산출물:** 샵 2개 라이브 준비 완료

## Week 2 — 첫 10개 출시
- [ ] Canva Bulk Create로 템플릿 10종 제작
- [ ] Claude로 리스팅 10개분 SEO 제목 + 태그 13개 + 설명 작성
- [ ] Etsy 10개 업로드 (썸네일은 Canva Mockup)
- [ ] Gumroad 번들 1종($19~29) 등록
- **KPI:** ✅ 라이브 리스팅 10 + 번들 1

## Week 3~6 — 출시 리듬 (가장 중요)
- [ ] **매주 5개 신규 리스팅** (하루 1개) → 6주차 누적 ~30개
- [ ] Pinterest 개설, 리스팅당 핀 2~3개 자동 생성(Canva)
- [ ] 매주 일요일: Claude에 판매 데이터 주고 "더블다운 vs 폐기" 분석
- [ ] 첫 판매 기록 (보통 이 구간 발생)
- **KPI:** 누적 30 리스팅 / 첫 매출 / 월 $100~300

## Week 7~10 — 확장
- [ ] 베스트셀러 변주 집중 → 누적 40+ 리스팅
- [ ] Gumroad 가격 사다리 구축: $9 / $29 / $49 (3~4종)
- [ ] 이메일 수집 시작 (Gumroad 구매자 → 후속 상품 알림)
- **KPI:** 월 $300~600

## Week 11~13 — 증폭기 탑재
- [ ] **Antigravity:** 메인 템플릿 컴패니언 웹툴 제작 (예: 계산기/대시보드) → 무료 리드마그넷 or $5 트립와이어
- [ ] **Gemini Veo:** 상품 소개 8초 영상 → Pinterest/Reels/Shorts 배포 ("Altered Content" 라벨 적용)
- [ ] 베스트셀러 묶음 → "메가 번들" $59 출시
- **KPI:** 월 $500~900 (목표 100만원 도달/근접)
