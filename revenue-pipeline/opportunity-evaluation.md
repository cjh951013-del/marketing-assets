## ③ AI 전자책 — ✅ 코어로 승격

**광고(leadgeny.kr)는 무시하세요. 그건 "강의를 파는" 퍼널입니다. 하지만 그 밑의 비즈니스 모델 자체는 당신 도구에 가장 완벽하게 맞습니다.**

- **왜 맞나:** Claude가 본문을 쓰고 → Canva가 표지·목차·상세페이지를 만들고 → Gumroad/Etsy가 글로벌 판매 → Payoneer로 USD 정산. **추가 결제·외부 도구 0원.** 가진 것만으로 끝.
- **2026 데이터:** 전자책은 Gumroad에서 가장 신뢰도 높은 스테디셀러 카테고리. 마진 90%+. ([conversionproplus](https://conversionproplus.com/blog/gumroad-trends-2026-what-s-selling-right-now))
- **핵심:** "AI로 썼다"가 아니라 **"구체적 고통을 해결한다"**가 팔림. 광고에 나온 *"읽씹 당한 카톡 되살리는 7가지 문구"*가 정확한 예시 — 초니치·즉시효용·충동구매.
- **실행:** 메인 전략(README)의 디지털상품 파이프라인에 **그대로 편입.** 전자책 = Gumroad 가격사다리의 $9~19 칸.

> **배치:** 메인 파이프라인의 1차 상품군. Notion/Canva 템플릿과 같은 "생산성·셀프헬프" 니치로 묶어 번들.

## ① 모바일 방치형 게임 — 🔄 게임은 장기 취미로, '자산'은 지금 돈으로

**솔직하게 (devil 모드):** 기획서 퀄리티는 진짜 인상적입니다. C# 코드, 21유닛 대칭 설계, 로어까지 — 실력이 보입니다. **하지만 이걸 "어렵지 않게 월 100" 엔진으로 쓰는 건 최악의 선택입니다.**

- 방치형 RPG는 **레드 오션 of 레드 오션.** 대형 스튜디오가 UA(광고비)로 도배하는 시장. 광고/IAP로 월 $730 벌려면 **DAU 수천 명**이 필요.
- 출시까지 아트·유니티 통합·밸런싱·사운드·백엔드·라이브옵스·스토어 ASO… **하루 2시간으론 6~12개월.** 그동안 수익 $0일 수 있음.
- 수익이 **후행적이고 불확실** — 가장 "쉽지 않은" 길.

**그래서 옮깁니다 — 게임을 버리지 말고, 게임을 *만들면서 나온 자산*을 지금 디지털 상품으로 파세요:**

1. **게임 기획서 자체** → "캣히어로풍 방치형 RPG 완전 설계서 + Unity C# 코드" 로 Gumroad 판매 ($29~49). 게임 개발자/인디 지망생 타겟. **이미 다 만들어져 있음.**
2. **캐릭터 아트팩 21종** → Gemini(나노바나나)로 렌더 → "Cute Flat 2D Animal Hero Game Asset Pack" Etsy/Unity Asset Store/itch.io 판매.
3. **아트 프롬프트 팩** → 21종 프롬프트 = "Flat Doodle Game Icon Prompt Pack" Gumroad ($9~15). AI 프롬프트 팩은 2026 인기 카테고리.
4. **방치형 RPG 시너지/밸런스 설계 템플릿** → Notion/스프레드시트로 → 게임기획 템플릿 판매.

> **배치:** 게임 본편 = **장기 패션 프로젝트(수익 KPI에서 제외)**. 게임 자산 4종 = **메인 파이프라인에 즉시 투입.** 이미 한 일을 현금화하는 거라 ROI 최고.

## ④ Printify POD — 🔸 선택적 보조 (서두르지 말 것)

- **합법·정상 모델이지만 당신에겐 디지털 상품보다 열위:** 실물 주문제작은 마진 박함(개당 $5~8), 배송/CS/반품 발생, Etsy POD는 포화 + 단속 강화 추세.
- 디지털 상품은 마진 90% + 풀필먼트 0. **같은 Canva 노력이면 디지털이 압도적.**
- **결론:** 디지털로 월 50만원이 안정되기 전엔 손대지 마세요. 나중에 베스트셀러 전자책/템플릿 디자인을 **티셔츠·머그로 확장**하는 보조 채널로만.
